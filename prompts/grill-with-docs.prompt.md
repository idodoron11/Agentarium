Run a grilling session combined with domain-modeling. Follow both skill files below together:

- For the interview loop, follow the grilling
- For capturing decisions as ADRs and building the glossary, follow the domain-modeling

Ask questions one at a time. After each answer, determine whether it warrants a new ADR entry or a glossary term — if so, draft it before moving to the next question. Continue until the plan is fully stress-tested and the domain model is captured.
